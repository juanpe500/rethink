01

Install & connect

1

Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the rethink-extension/ folder.

2

Pin the ✦ icon. Click it → Settings → paste your OpenRouter key → Save.

3

Choose model… opens the full settings page with the model selector across OpenRouter's whole catalogue.

02

The loop

→

Activate rethink mode from the popup, then hover the page — every block outlines, with softer borders the deeper it nests, and a ✦ rethink pill floats at its top-right.

→

Click a block to lock it. The pill morphs into a textarea that grows from a single line as you type.

→

Type your instruction, pick a mode, press Enter. The block's HTML plus its matching CSS go to your model; the reply is applied in place.

→

Undo · again · done appear afterward. Esc exits.

03

Three modes, three contracts

Restyle everything

Rename or add classes, introduce tags, change the structure freely.

✓Every id & data-* preserved
✓Kept-by-id nodes grafted back live — listeners survive
✓Dropped ids stashed in a hidden vault

Restyle classes

Only the class and inline style may change.

✓Trees walked in lockstep, class/style copied
⊘New nodes, tag renames, id edits discarded
✓Live nodes never replaced — all listeners intact

Full freedom

Anything, as long as it's valid, script-free HTML.

✓No structural constraints
✓<script> stripped by contract
✓One-click undo restores the original
04

How it's wired

manifest.json          MV3 · content script on <all_urls> · popup · options
background.js          service worker — settings, OpenRouter call, model list
                       (the BYOK key lives here, never in a page's JS world)
content/content.js     nested-outline highlight, morphing textarea,
                       CSS harvest, and the three mode-enforcing appliers
popup/                 Main (activate · mode · model) · Settings (BYOK key)
options/               full-page config; hosts the ai_model_selector modal
vendor/                juanpe500/ai_model_selector, vendored (MIT)

Popup arms the tab → the content script highlights & harvests → sends {prompt, html, css, mode} to the worker → the worker calls OpenRouter with a mode-specific system prompt → the content script applies the reply under that mode's rules.

05

Known edges

  • Runs in the top frame only — cross-origin iframes aren't reached.
  • Cross-origin stylesheets can't be read for CSS harvest (browser security) and are skipped.
  • Can't run on chrome://, the Web Store, or other privileged pages.
  • Listener re-hooking covers elements kept by id; listeners on intermediate nodes the AI restructures away are lost by design.
